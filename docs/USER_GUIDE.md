# MGS Tone Craft 操作ガイド（v0.368）

このガイドは MGSTC v0.368 の操作を説明します。配布版ごとの内容・公開状況は[README](../README.md)からReleases一覧を確認してください。画面や操作は今後変わる場合があります。設定のViewから表示倍率を変更すると、VST3の編集画面もホストへサイズ変更を要求し、開いたまま倍率を反映します。

MGS Tone Craft は、OPLL、SCC、PSG を重ねた複合音色を作る Windows アプリです。音を聴きながら編集し、MGSC 向けの音色定義や演奏設定を書き出せます。Standalone 版と VST3 版で、共通の編集画面と音色ライブラリを使えます。

VST3 版では、音声出力と演奏用 MIDI 入力を DAW 側で設定します。アプリ内の PC 音声出力・MIDI 入力設定とは別です。総合音色とマスターボリュームは、プラグインごとに DAW のプロジェクトへ保存・復元されます（Plugin State）。保存した音色は、ライブラリとは独立して復元できます。

## 画面を開く

- **Standalone 版**：通常起動では「エディタ選択」が開きます。複合音色／OPLL音色／SCC音色のカードをクリックするか、Tabで選びSpace／Enterで開きます。100%表示時のカードは190×190、画像は100×100ドットです。右上から設定も開けます。各エディタ上部のナビゲーションで他の2種類を追加表示でき、最大3種類を同時に編集できます。同種の画面は再利用し、最小化中なら復元します。各画面を閉じても他のエディタは開いたままで、複合音色エディタも同じ扱いです。閉じた画面はアプリ終了まで編集状態を保持し、最後のエディタを閉じると未保存の変更を確認してアプリを終了します。
- **VST3 版**：DAW からプラグインの編集画面を開きます。初期状態の PSG レイヤーを編集するか、必要な音源を追加してください。

各エディタのエミュ／実機切替の左にある `グラフ` から、試聴音を解析する共通の画面を開けます。`ライブラリ管理` は別ウィンドウで開くため、音色の編集画面と並べて使えます。

## 実機出力で問題が起きたとき

MAmidiMEmoの送信キューが満杯になると、状態欄に送信輻輳や再同期待ちが表示されます。内蔵エミュレータの演奏は続き、PC音声はミュートのままです。波形モニタの設定も変わりません。

実機は送信済み処理と全音源の消音の応答を確認してから、次に押した鍵盤で演奏を再開します。それまで保持していた音は自動で鳴らし直しません。接続や消音応答のエラーが表示された場合は、接続先と実機の状態を確認し、設定の`Output`で再接続してください。通信障害中は実機の消音完了を保証できません。

出力切替・再接続・設定変更で制御の待機がタイムアウトした場合、操作は適用されず、変更した設定も保存されません。処理が落ち着いてからやり直してください。制御の待機には500 msの期限がありますが、RPC接続やDNS解決、通信・終了処理を含む操作全体が500 ms以内に終わる保証ではありません。

## 総合音色を編集する

総合音色では、PSG、SCC、OPLL のレイヤーを同じ時間軸に並べます。

1. `+ チャンネル` を開き、`PSG 追加`／`SCC 追加`／`OPLL 追加` から使う音源を選びます。概要欄の `複製` や `削除` で構成を調整できます。
2. チャンネルの `初期設定 / 編集` で、発音前の音色、音程、変調などを設定します。
3. 時間軸で音量、音程、音色切替、レジスタ変更、休符、ループを編集します。

`編集に集中` を使うと、概要と MIX 行が隠れ、編集領域を広く使えます。

音色を切り替えるには、音色（`@`）のカウントを選びます。開いた音色選択画面で、ライブラリ音色や対応する ROM 音色・SCC プリセットを試聴し、読み込んでください。そのカウントへ音色が割り当てられます。SCC／OPLL レイヤーの波形やパラメーターは、`単音色編集` から編集できます。

割り当てた音色は、総合音色の中にコピーして保持します。後から単音色ライブラリを変更しても、総合音色の内容は変わりません。

画面上部には `MGSCプレビュー`、`グラフ`、即時発音などの操作があります。独立した `SCC音色`／`OPLL音色` ボタンはStandalone用で、VST3では表示せず総合のレイヤーを編集します。総合音色の `開く`／`保存` は編集中の総合音色全体を扱います。`MGSCソースを開く`／`MGSCソースを書き出す` は MGSC 定義ソースの入出力です。コピー／貼り付けも総合音色または MGSC ソースを扱い、曲全体の MML/MUS を生成する機能ではありません。

音量は0～15を等間隔で編集し、チップ固有の論理カーブを重ねて確認できます。「自動変化」は開始から終端までの線を設定し、MGSCのランプ定義へ変換します。

演奏中は、各レイヤーのエンベロープ領域に、そのレイヤーへ割り当てられた物理チャンネルの波形を重ねて表示します。ポリ演奏では最後に押した鍵盤を表示対象とし、離鍵後も次の発音までリリース中の波形を表示します。MIXは全体の合成波形です。OPLL単音色エディタの波形は、同時発音中の音とリリースを合成した表示です。

総合画面の上部にある波形表示の `自動`／`共通` で、振幅の見方を切り替えられます。`自動` は波形ごとに拡大して形を確認します。`共通` は同じ尺度で、音源別の音量とマスターボリュームを反映したレイヤー間の振幅差を比較できます。MIXにはDC除去とクリッピングも適用されるため、各レイヤーの単純な和とは異なる場合があります。尺度を超える部分は表示枠で切り取ります。この切替で音や保存音色は変わりません。

周期的な波形は表示位置を揃えます。ノイズ、デチューン、LFOなどの変化を含み、周期が安定しない場合は最近の波形を表示します。表示負荷が高い場合は同期精度と波形の更新頻度を下げ、負荷が回復すると通常の更新頻度へ戻します。新しい発音の表示を優先します。

共通スケールは現在のマスターボリューム設定を反映します。VST3出力の短い音量平滑化中は、実音の振幅と一時的に異なる場合があります。実機出力中の波形モニターは内蔵シミュレーションによる参考表示です。

`MGSCプレビュー`を押すと、編集画面とは別のウィンドウを開きます。上段は選択レイヤーのMML、下段は総合音色をCtrl+Cでコピーしたときと同じ全体ソースです。選択や編集に合わせて更新され、各枠で文字を選択してコピーできます。ウィンドウのサイズと、中央の仕切りを上下にドラッグしたときの表示比率を調整できます。総合編集画面より前に表示し、SCC／OPLL単体編集画面との表示順は操作に従います。表示倍率はViewの全体設定に従い、編集窓のCtrl±による倍率とは独立しています。

演奏位置の縦ラインは、編集用の選択ステップとは別に、各レイヤーの作者カウントを示します。押鍵中は末尾の保持区間もENDまで進み、ループ終端で開始位置へ戻ります。発音開始ディレイにも従い、ズーム・スクロール後も編集操作を妨げません。表示更新は60Hzを目標とし、演奏処理を優先するため画面表示が遅れる場合があります。

初期設定の `h` からソフトウェアLFOを編集できます。波形は約60Hzの水平保持と垂直な変化で表示し、縦軸は音程オフセット±127です。PSG／SCCの `p` と `h` は同時に使えません。

PSGの「初期設定 / 編集」にあるMode／Noiseは、発音前のMML `/<モード>`／`n<ノイズ周波数>`を設定します。Mode 0はMute、1はTone、2はNoise、3はMixです。エンベロープ定義のMode／Noiseは「カウント編集」側へ分けています。定義側のMode 0は変更なしで、Muteとは異なります。両方0の設定だけではエンベロープを追加せず、どちらかを非0にすると定義へ保存・出力します。Mode 1ではNoise周期を変えず、Mode 2／3ではNoise 0も有効です。既存データの定義設定をトラック設定へ自動移動しません。

PSGエンベロープでは、Y-Register yの下に `モード /` と `ノイズ周波数 n` を表示します。Mode 0はMute、1はTone、2はNoise、3はMixです。同じステップ内のループ開始`[`より前（初回のみ）と後（毎周実行）へ、モードとノイズを別々に指定できます。ノイズ周波数は0～31で、Noise LFOから往復・上昇・下降・自由曲線の変化を設定できます。`ランダム`を押すたびにEND設定位置まで0～31の値列を作り直し、1秒試聴を開始します。Noise設定は `LFO / Modulation` の一番下にあります。自由曲線の開始カウント・深さ・変化・粗さ・停止は、カウント編集の `設定` または入力欄のEnterで確定します。モード値欄には、手動 `y7` の変更も選択チャンネルとループ前後に合わせて反映します。PSGには音色 `@` 編集欄がなく、PSG／SCCにはTL・FBの変調欄がありません。

### WAVから複合音色を作る

総合音色の `WAV変換` からWAVファイルを開き、範囲を選んで `範囲を解析` を押します。基準音高とキーオフを確認したら、音源構成・2ch分担・最適化方針を選び、`変換 / 再変換` を実行します。現在の解析上限は60秒です。

既存のSCC単音、SCC × SCC、SCC × OPLL固定、SCC × OPLLオリジナルに加え、次の3構成を使えます。

- SCC × OPLLパッチスライド
- OPLLオリジナル × OPLLパッチスライド
- OPLLパッチスライド × OPLLパッチスライド

すべての2ch構成で、自動、基音＋残りの倍音、低次倍音＋高次倍音、アタック＋持続、独立最適化を選べます。SCCを含まない構成では、SCC音色数・ポイント音色数・SCC波形生成は「該当なし」になります。SCC構成へ戻すと以前の値を使えます。

パッチスライドは配置済みDBのAUTO_SAFE候補から探索し、ROM音色の変更順序と1～2カウントの保持時間を保ちます。DBが利用できない場合や候補がない場合はエラーを表示し、前回の有効な結果を残します。

候補を選び、PC鍵盤／MIDIや `変換音 ▶` で確認し、`原音 ▶` と比較してください。試聴だけでは編集は確定しません。**適用すると、編集中の総合音色全体を置き換えます。** 残したい未保存の音色は先に保存してください。適用は1回のUndoで戻せます。閉じる・キャンセルでは適用しません。生成結果は通常の総合音色として保存・再読込・MGSC出力でき、保存後の演奏にDBは不要です。

複合音色からSCC／OPLLの音色編集を開いた場合は、鍵盤のPoly／Monoの左で「単音色」と「複合音色全体」を切り替えられます。初期状態は「複合音色全体」です。「単音色」は編集対象レイヤーだけを、元のエンベロープ・音程・開始遅延で演奏します。切替では編集や保存は確定しません。通常の単音色エディタには、この切替は表示されません。

## SCC 単音色を編集する

SCC エディタでは波形グラフをドラッグして32サンプルを描き、各値を10進／16進欄で編集できます。平均化、正規化、反転、位相移動、上下反転、縦倍率などの波形操作もあります。

波形プリセットを使う場合は、倍音倍率と置換／マージ条件を調整します。確定前の候補を表示・試聴し、`A/B` で確定波形と比較してください。`適用` で確定し、`取消` で候補を破棄します。

数値入力欄は分解能を選び、最大32個の値と補間演算子を使って波形を入力します。括弧で入力値の時間配分を指定できます。有効な式は入力と同時に反映され、Undo／Redo では波形、分解能、式をまとめて戻せます。詳細は[数値波形入力ガイド](SCC_NUMERIC_WAVE.md)を参照してください。

SCC編集ウィンドウはOPLL単音色・複合音色エディタと共通の高さです。SCCWAVのCopy／Pasteは、入力行に収まる小さなアイコンボタンで操作し、縦倍率の下には現在の倍率を%表示します。ツールバーからは、MGSC の `@s` 定義を `.txt` ファイルで読み書きできます。貼り付けは、クリップボードにある WAV 音声を優先します。WAV がなければ画像を背景画像として読み込み、それ以外は MGSC テキストとして扱います。

> 文字コードの補足：MGSCテキストをコピーすると、UnicodeとANSI（CP932）の両形式をクリップボードへ登録します。

`WAV変換` は、WAV ファイルやクリップボードの音声から利用でき、Audacity は不要です。`Audacityから変換` を使う場合だけ、次の準備をしてください。

1. Audacity の「編集」→「環境設定」→「モジュール」を開きます。
2. `mod-script-pipe` を有効にし、Audacity を再起動します。
3. Audacity で変換したい範囲を選び、MGSTC の `Audacityから変換` を実行します。

**`mod-script-pipe` が有効な間は、他のプログラムからも Audacity を操作できます。利用しないときは無効に戻してください。**

## OPLL 単音色を編集する

OPLL エディタでは MOD／CAR の AM、PM、EG、KR、波形、MULT、KSL、TL、AR、DR、SL、RR、FB などを編集できます。オリジナル音色のエンベロープ表示や `@v` プレビューは編集内容に追従します。

固定ROM音色は15種類で、MGSC番号 `@0`～`@14` から選択して試聴できます。一般的な1始まりの音色番号とは表示が異なるため、外部資料の番号ではなく画面の `@` 番号を確認してください。ROM音色を編集するには、`編集音色へ読込` でオリジナル音色へコピーしてから編集します。

ツールバーから `.txt` の MGSC `@v` 定義を読み書きし、コピー／貼り付けや Undo／Redo を利用できます。WAV変換の結果は候補として確認してから適用します。

## 試聴、PC鍵盤、MIDI

- 画面鍵盤は `C1`～`B8`。クリック／ドラッグで発音します。
- PC鍵盤の下段は `Z S X D C V G B H N J M`（Z が基準オクターブの C）、上段は `Q 2 W 3 E R …` です。
- `Page Down`／`Page Up`（画面上は `PgDn`／`PgUp`）でPC鍵盤のオクターブを移動します。`Ctrl` を押している間は PC 演奏を止めます。
- 鍵盤上部の `Poly`／`Mono` で発音モードを選びます。テキスト入力欄にフォーカスがある間は PC 演奏を抑制します。
- Standalone の MIDI 入力デバイスはアプリ設定の `MIDI` タブで選択します。入力機器の接続状態は鍵盤付近に表示されます。VST3 では DAW からの MIDI を使います。
- スピーカーの即時発音をONにすると、対応する音色編集の変更時に最後に手動演奏した音程を約1秒試聴します。OFFでも鍵盤、PC、MIDIによる手動試聴は使えます。

### 音をスペアナで確認する

スペアナは、総合／SCC／OPLL の各エディタから開く共通のウィンドウです。`スペクトログラム` と `スペクトラム` を切り替え、音源色または疑似カラー、強調率、履歴、ピーク情報などを確認できます。

スペクトラムでは最大5秒の履歴を表示し、`比較用に保持`で基準を残した比較、表示停止と履歴位置の確認ができます。スペアナ操作中も直前のエディタへ鍵盤入力を送れます。

ピン留めすると、スペアナをMGSTCのほかのウィンドウより前に保ちます。Windows全体で常に最前面になる機能ではなく、他のアプリを前面にすると覆われます。

## 音色ライブラリとセット

単音色／総合音色エディタの `ライブラリ管理` から一覧を開きます。タブは `音色一覧`、`パッチスライド`、`タグ管理`、`インポート`、`エクスポート` です。一覧ではカテゴリ、文字検索、タグ、★、並べ替えで絞り込み、選択音色の詳細確認、試聴、編集、複製、削除、タグ付与を行います。複数のタグを選んだ場合は、すべてを含む音色が表示されます。標準タグは94件で、独自タグも追加できます。

### セットで音色を整理する

`ツリー` を ON にすると、セットと未所属音色を表示します。セットの追加、複製、改名、メモ編集、削除は音色本体の削除とは別です。セット内の音色を通常ドラッグするとセット間で所属を移動し、Ctrl+ドラッグでは所属を追加します。同一セット内のドラッグは並べ替えです。セット内の音色を削除する操作は所属解除であり、音色一覧からの削除はライブラリ本体を削除します。削除前の確認を読んで対象を確かめてください。

### 編集した音色を保存する

単音色画面では、右側のライブラリから `読込`、`保存`、`別名保存`、`名前変更`、`削除` などを使います。既存音色を複製するには `読込` の後に `別名保存` します。総合画面では `保存 / ライブラリ` を使います。独自タグの名前変更・統合・削除は全音源のライブラリが対象で、標準タグは変更しません。アプリ内のユーザー音色ライブラリは `%LOCALAPPDATA%\MgsToneCraft\tone_library.sqlite` にあり、インストール／更新では削除されません。

## OPLL PatchSlide を探す

`ライブラリ管理` の `パッチスライド` タブでは、配置済みの OPLL PatchSlide データを探索できます。同じDBは最初の検証後にアプリ内で共有され、編集側の検索画面を閉じても毎回読み込み直しません。初回の待ち時間は、WAV変換と同じアニメーション付き進捗窓で処理段階を確認できます。DBが変更された場合や、読込を取り消した場合は必要に応じて再検証します。配布用の compact 版には12,180候補があり、初期版のデータには13,950候補があります。使用するデータの版によって件数は異なります。上部のトグルで「タグから探す」「分類タグから探す」「全ての音色」を切り替えます。タグ検索では複数選択の説明右にあるANDで選んだタグのすべて、ORでいずれかに一致する候補を探します。分類検索では16群／64群のトグルと、その右の群選択を使います。`Standard B` は距離順位による比較候補、`Variation` は別の候補選出です。候補を選んで試聴し、一時ストックへ追加できます。

`編集へ適用` では OPLL レイヤーへの追加または既存レイヤーの置換先を確認して適用します。適用は総合音色の編集で、共有 PatchSlide データは変更しません。候補の安全分類を確認してください。通常一覧では Reject 候補は隠され、`不安定な音色も表示 (注意)` を明示したときに表示されます。PatchSlide タブにデータの不足や不整合が表示された場合は、PatchSlide 機能だけが利用できません。

### 編集中のOPLL音に近い候補を探す

総合音色エディタでOPLLのシーケンスエンベロープを開き、「音色 @」行の「パッチスライド」を押します。「編集中の音から近似」は、そのOPLLレイヤーだけの音を検索キーにします。候補が表示されたら選択して試聴します。Variationは選択した候補からの探索です。検索中の「停止」で検索を取り消せます。

画面下部の「停止」の右で「パッチスライド単体」と「複合音色全体」を切り替えられます。初期状態は「複合音色全体」です。「2回変更」の右にあるA/Bは、A＝編集画面の元の音色、B＝選択したパッチスライドを交互に試聴します。ボタンには次に試聴する側が表示され、鍵盤でも最後に選んだ側を演奏できます。この試聴切替とA/Bは音色ライブラリには表示しません。複合音色全体では、対象レイヤーへ候補を仮適用して他レイヤーと重ねます。試聴だけでは編集は確定しません。検索結果が更新されても、鍵盤の音色は最後に明示選択した候補を保持します。別の候補を選ぶと切り替わります。

「編集へ適用」は、開いたときのOPLLレイヤーの初期音色とすべての音色変更を置き換えます。**同じレイヤーのTL／FB変調と手動y設定も削除します。** 音量・音程などの設定と他レイヤーは保持し、短いエンベロープは終端音量を維持して必要長まで延ばします。ループと衝突するときは変更案を確認し、取り消せば元の編集状態を保ちます。確定後は1回のUndoで元へ戻せます。音量の値・カウント・自動変化・詳細設定は保持します。自動変化は既存の処理で音色変更位置ごとに分割されるため、途中の実音量値が変わる場合があります。

検索中に元の音色が変わった場合は、画面を閉じて検索し直してください。SCC／PSGと読み取り専用のRateエンベロープは対象外です。ライブラリ管理タブの適用は従来のレイヤー置換であり、この部分適用とは操作が異なります。

## 外部音色のインポートとエクスポート

`インポート` タブで対応ファイルを開くと、見つかった完成音色が候補として一覧に加わります。対応形式には非圧縮MGS、MML／MUS定義、MuSICA VCD、SCC-Musixx SNG、VGM／VGZがあります。圧縮MGSや完成音色として特定できないデータは候補になりません。読み込みだけではライブラリに保存されません。候補を試聴し、名前や★を確認し、チェックした項目を `選択項目を登録` で登録します。候補の `編集` は未登録状態で対応エディタへ開きます。インポート候補はアプリ終了まで保持されます。

VGZは展開後256 MiBまで読み込めます。メモリ使用量を抑えるための上限であり、超過したファイルはエラーとなり、候補は追加されません。

VGMのデータブロックが途中で切れている場合や、指定された長さがファイルの残りを超える場合は、その地点で解析を打ち切ります。それ以前に見つかった完成音色だけが候補になります。

候補名の既定は `接頭辞 - 識別子` です。曲名がなければファイル名、音色番号・音色名がなければ `00` からの連番を使い、登録前に変更できます。MGS／MMLの総合候補は実際に使われた `@e` を基に作ります。OPLLの7～9chはリズムが有効な時点の音色候補から除外します。参照定義の不足には警告や音源初期値による補完があるため、候補と警告を確認してください。

`.mgstc` も `インポート` タブから開けます。この形式は、内容と登録の確認を終えるとライブラリへ追加されます。他の対応形式のように、`選択項目を登録` を押すまで未保存の候補として残るわけではありません。右パネルから音色を1件ずつ取り込む操作も利用できます。

### Furnace の音色を取り込む

`インポート` タブは `.fui` と `.fuw` も受け付けます。Furnaceインストゥルメントは対応する音源種別とデータだけが候補になり、非対応の音源種別やOPLLドラムは読み込みません。Furnaceの波形はSCC用32サンプルに変換され、元が32サンプル以外なら候補に `[コンバート]` が表示されます。新しいFurnace版や未対応マクロには警告が付くことがあります。

### 音色やセットを書き出す

`エクスポート` タブでは、一覧から追加した音色やセットを書き出します。形式は単音色・総合音色・セットの `.mgstc`、Furnace `.fui`、SCC波形 `.fuw` です。Furnace形式はMGSTCの全編集情報を表現するものではありません。特に総合音色からの `.fui` はレイヤーごとの静的な音色設定のみの部分変換で、`.fuw` はSCC波形のみを書き出します。結果に表示される警告・変換内容を確認してください。既存ファイルへ書き出す場合の上書き／連番／スキップ選択を確認します。

右パネルの `.mgstc` `取込`／`書出` は単一ライブラリ項目の交換です。これは `インポート` タブの外部演奏ファイル解析とは別の操作です。総合 `MGSCソースを開く`／`MGSCソースを書き出す`、SCC／OPLLの `.txt` 入出力はMGSC音色定義の操作です。

## アプリ設定と保存データ

右上のアプリ設定には `View`、`MIDI`、`Output`、`About` タブがあります。`View` は75%／100%／125%の表示倍率、`MIDI` はStandaloneの入力機器と受信条件、`Output` はPC音声出力と試聴経路の設定です。Output の選択によっては ASIO ドライバーなど環境固有の設定が必要です。マスターボリュームは0～100%で全画面が共有し、チップの音量値を変えず最終出力レベルを調整します。Standaloneでは再起動後も復元します。編集画面の `Ctrl` + `+`／`-` は倍率の一時上書き、`Ctrl+0` はViewの設定値へ復帰します。ウィンドウの位置・サイズは保存しません。

Standaloneで「音声切替待ち」と表示された場合は、旧音声処理の停止・回収を待っています。回収が終わるまで、新しいWASAPI／ASIO出力は始まりません。待機中にOutputで再適用すると、最新の選択が回収後に適用されます。

終了時に回収が残っている場合は「終了待ち」を表示します。「終了を取り消す」で画面に戻れますが、停止した演奏は再開しません。デバイスや音声処理が応答しない場合は、安全な回収を確認できず、正常終了が完了しないことがあります。

### 更新前のバックアップと互換性

**更新前に、重要な音色と保存ファイルをバックアップしてください。** v0.285の旧独自形式 `timbre-library-v1.mgstc` と `composite-timbre-library-v1.mgstc` は、v0.365へ直接読み込むことも、自動移行することもできません。元ファイルの保管だけでは、新版でそのまま使えるようにはなりません。旧ファイルを消さずに保管し、利用する音色に対応した移行方法が確認できるまで保持してください。

現在の音色ライブラリ `tone_library.sqlite` は、Alpha 版を含め、保存した音色・セット・タグなどの意味を保って読み込む互換性の対象です。保存構造は SQLite Schema v2 で、対応する旧構造から段階的に移行します。この方針は、旧独自形式のライブラリとは別です。

DAW のプロジェクトには、プラグインごとの総合音色を音色ライブラリとは独立して保存・復元します。設定 INI、単体 `.mgstc`、複合音色のポータブルファイルには、版をまたぐアップグレード互換の保証はありません。また、音源の計算方法が変わると、過去と同じ出音になるとは限りません。重要な音色は、MGSC 定義の `.txt` などにも書き出して保管してください。

## MGSCについて

SCC／OPLLのプレビューと `.txt` は各音色定義（`@s`／`@v`）です。総合音色のMGSCプレビュー／ソースには音色定義に加え、エンベロープ等の演奏設定が含まれます。どちらも曲全体の完成した `.MUS` を書き出すものではありません。単音色の一時出力番号はSCCが0～31、OPLLが15～31で、プレビューの番号に反映します。入力欄以外では `Ctrl+C`／`Ctrl+V` で定義をコピー／貼り付けできます。
