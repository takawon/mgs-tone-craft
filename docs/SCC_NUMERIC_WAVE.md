# SCC数値波形入力ガイド

SCC 音色エディタでは、数値を入力して32サンプルの波形を作れます。最大32個の値を並べるほか、5種類の補間で値の間をつないだり、括弧で時間配分を変えたりできます。作った式はクリップボードで共有できます。Standalone 版と VST3 版で操作は共通です。

まず入力欄の左で分解能を16にし、`0 15` を入力してみてください。前半が最小値、後半が最大値の波形になります。続いて `0-15` に変えると、最小値から最大値へ直線的に変化する波形になります。**有効な式は入力と同時に反映されます。**

## 値と分解能

入力欄の左にある分解能で、使える整数の範囲を選びます。

| 分解能 | 入力できる値 |
| ---: | ---: |
| 16 | 0～15 |
| 32 | 0～31 |
| 64 | 0～63 |
| 128 | 0～127 |
| 256 | 0～255 |

0は波形の最下段、最大値は最上段です。初期分解能は256です。数値はSCCの符号付き8bit値へ変換されます。たとえば、16段階では0が-128、15が127になります。256段階では0が-128、128が0、255が127になります。

入力値の間に演算子がなければ、その値を担当するサンプル区間で保持します。区切りは半角スペースです。前後の空白と複数の連続した空白を使えます。

| 入力 | 32サンプルへの配分（16段階） |
|---|---|
| `0 15` | 0を16個、15を16個 |
| `0 15 15 15` | 0を8個、15を24個 |
| `0 15 15` | 0を11個、15を21個 |
| `0 (15 15)` | 0を16個、15を16個 |

サンプル区間の詳しい配分は、後半の[詳しい計算規則](#詳しい計算規則)を参照してください。

## 補間

数値間に演算子を置くと、接続先の時間区間で補間します。5種類の演算子は以下の曲線を使います。すべて上昇と下降の両方で使用できます。

| 演算子 | 曲線 | 動き |
|---|---|---|
| `-` | `f(t) = t` | 線形 |
| `>` | `f(t) = 1 - cos(πt/2)` | 左側が緩やかで、右側が急 |
| `<` | `f(t) = sin(πt/2)` | 左側が急で、右側が緩やか |
| `><` | `f(t) = (1 - cos(πt))/2` | 両端が緩やかで、中央が急 |
| `<>` | 前半`sin(πt)/2`、後半`1 - sin(π(1-t))/2` | 両端が急で、中央が緩やか |

| 入力 | 時間配分 |
|---|---|
| `0-15` | 32サンプルすべてで0から15へ線形補間 |
| `0-15-0` | 16サンプルで0から15、次の16サンプルで15から0 |
| `0><15><0` | 16サンプルずつ、両端緩・中央急の2区間 |
| `8<15>8<0>8` | 8サンプルずつ4区間を接続 |

`><`と`<>`はそれぞれ独立した2文字演算子です。演算子の前後に空白を置けます。たとえば`0>15`、`0 > 15`、`0> 15`、`0 >15`は同じ式です。ハイフンはASCIIの`-`を使います。U+2010の`‐`も入力できます。負数は使えません。

### 詳しい計算規則

波形がどのように32サンプルへ割り当てられるか、数値を厳密に確認したい場合の説明です。通常の入力は上の例から始められます。

区間を複数の要素へ分けるとき、整数境界は`boundary(j) = start + ceil(j × W / N)`で求めます。`W`は区間幅、`N`は要素数です。たとえば32サンプルを3分割すると11／11／10、8サンプルを3分割すると3／3／2になります。0サンプルとなる要素があっても式はエラーにならず、最終波形は常に32サンプルです。

`t` は区間内の進行率（0～1）で、補間値は `a + (b - a) × f(t)` から求めます。各区間は `t=0` から始まります。補間演算子で連続してつながった区間を、ここでは「チェーン」と呼びます。

- チェーンの途中の区間は、幅 `N` に対して `t=j/N` で計算します。
- 終点が始点へ戻らないチェーンでは、最後の区間だけ `t=j/(N-1)` とし、最終値まで到達させます。
- `0-15-0` のように、始点と終点が同じ値でつながるチェーンでは、最後を含むすべての区間を `t=j/N` とします。接続値を出力するのは、次の区間の先頭だけです。

値を保持する区間や、演算子で接続していない独立したグループがあると、そこでチェーンが区切られます。式の最初と最後の値が同じだけでは、閉じたチェーンにはなりません。括弧をまたいで演算子で接続した場合も、判定方法は同じです。

幅が1サンプルの区間は `t=0`、幅が0の区間は出力なしとして扱います。計算結果は、選択中の分解能の整数値へ丸めてから SCC の値へ変換します。

## 括弧と補間の接続

括弧は内部要素が占める時間幅を決めます。繰り返しは行いません。括弧は最大16階層まで入れ子にできます。過大な入力はステータス欄でエラーとなり、波形を変更しません。

```text
0 (15)
```

は`0 15`と同じ時間配分です。括弧の中が複数の要素なら、そのグループの幅をさらに分けます。

```text
0 (15 15)
```

は0を16サンプル、15を合計16サンプル保持します。内側の2つの15がそれぞれ8サンプルを担当します。

```text
0 (15 (0 15))
```

は順に0を16サンプル、15を8サンプル、0を4サンプル、15を4サンプル保持します。

括弧による時間配分と補間による接続は別々に決まります。演算子は括弧を越えて直前の数値と直後の数値を結び付けます。括弧自体は数値や補間値を持ちません。例の式はすべて16段階です。

```text
0 > (15 0)
```

```text
0 (> 15 0)
```

この2つは同じ波形です。配分は次のとおりです。

| サンプル | 値または接続 | 幅 |
|---|---|---:|
| 0～15 | 0を保持 | 16 |
| 16～23 | 0から15へ`>`補間 | 8 |
| 24～31 | 0を保持 | 8 |

括弧境界をまたぐ接続は、外側の演算子をグループ先頭へ移しても同じ波形になります。これは5種類すべてに適用されます。

| 同じ波形になる入力（16段階） |
|---|
| `0>(15 0)` と `0(>15 0)` |
| `0<(15 0)` と `0(<15 0)` |
| `0><(15 0)` と `0(><15 0)` |
| `0<>(15 0)` と `0(<>15 0)` |
| `0-(15 0)` と `0(-15 0)` |

グループの先頭値へ外側から接続すると、補間はその先頭値が担当する幅を使います。残りのグループ内要素もグループ幅を使って配分します。

```text
(0 8) > (15 0)
```

左グループの最後の値8から、右グループの最初の値15へ接続します。左と右のグループはそれぞれ16サンプルです。右グループ内では、接続する15の区間と後続の0の区間がそれぞれ8サンプルを担当します。

同じ接続は括弧の位置を変えて書けます。

```text
(0 8) (> 15 0)
```

左側がグループの場合も、最後の数値から右側へ接続します。次の式では、左グループ内の0と15をそれぞれ8サンプル保持し、その後の16サンプルで15から外側の0へ補間します。

```text
(0 15)>0
```

入れ子の括弧でも、数値の接続を妨げません。

```text
0 > ((15 0) 8)
```

この式は外側の0を、最も内側の先頭値15へ接続します。括弧内の時間幅を決めた後、15が担当する区間に補間を適用します。

入れ子グループを含む次の2つは同じ波形です。

```text
0>((15 0) 8)
0((>15 0) 8)
```

16段階での時間配分は、先頭の0を16サンプル保持し、続くグループ内では0から15へ4サンプル補間、0を4サンプル保持、最後の8を8サンプル保持します。

別の接続列を含む次の2つも同じ波形です。

```text
0>(15-0)
0(>15-0)
```

この組み合わせでは、先頭の0を16サンプル保持した後、0から15へ8サンプル補間し、続く8サンプルで15から0へ線形補間します。

括弧の有無によって時間配分が変わることがあります。

```text
0 > 15 0
0 > (15 0)
```

上の2つは、同じ波形とは限りません。前者は`0>15`の補間列と後続の値0を分配します。後者は値0と、2要素を含むグループの幅を分配します。式の要素と括弧をそのまま確認してください。

### 入力エラーを直す

同じ数値の間に補間演算子を重ねることはできません。たとえば `0>(>15 0)` はエラーですが、別々の接続に演算子を指定した `0>15<0` は有効です。

括弧が閉じていない場合、余分な閉じ括弧がある場合、空のグループ `()` がある場合もエラーになります。入力した文字列は欄に残るので、そのまま修正できます。**エラーの間は、波形と履歴を最後の正常な状態に保ちます。**

## 入力・分解能・履歴

有効な式は入力と同時に波形へ反映されます。Enterや適用ボタンは不要です。未完成の式を入力している間は最後の正常な波形を保ちます。エラーは既存のステータス欄に表示され、入力フォーカスや選択範囲を移動しません。

数値入力欄は通常のテキスト欄と同じように選択、挿入、削除、Cut／Copy／Pasteを使えます。複数桁の数値入力は1回のUndo操作にまとめられます。分解能変更、波形式の一括貼り付けもそれぞれ1回でUndoできます。Undo／Redoでは32サンプル波形、分解能、元の式を一緒に復元します。波形が同じでも式が変わった編集は保持されます。

分解能を変えると、数値リテラルだけを次の式で再量子化します。

```text
newValue = round(oldValue × (newResolution - 1) / (oldResolution - 1))
```

たとえば16段階の`0>(8 15)`を256段階へ変更すると、`0>(136 255)`になります。括弧と演算子の位置はそのままです。

マウス、DEC／HEX、プリセットなどから確定波形が変わると、分解能を256にして32個の値`符号付きSCC値 + 128`へ式を置き換えます。確定されていない候補プレビューは入力式を変えません。

## SCCWAVで共有する

1. 数値入力行の `Copy` を押します。現在の分解能と式が、次の形式でクリップボードへ入ります。

```text
SCCWAV L=16 0>(15 0)
```

2. 受け取った式を読み込むには、`Paste` を押すか、数値入力欄で `Ctrl+V` を押します。共有テキストを直接入力することもできます。

`SCCWAV L=` の後には分解能と式が入ります。分解能は16／32／64／128／256です。`Copy` は括弧と演算子をそのまま残し、32個の数値へ展開しません。ヘッダは欄の中で1つだけ使ってください。

```text
SCCWAV L=16 0>(15 0)
SCCWAV L=16 0(>15 0)
SCCWAV L=16 8<15>8<0>8
SCCWAV L=256 128><255><0
```

数値だけを貼り付ける場合は、現在の分解能を使います。`SCCWAV L=...`付きの式を貼り付けると、ヘッダの分解能へ切り替わります。分解能を含む共有形式は式と波形を1回のUndoで復元します。

`SCCWAV L=16`のようにヘッダだけの入力は、式を続けて入力できる未完成状態です。波形は変わりません。以前の`SCCNUM/1`形式は使いません。

## 簡易ヘルプ

数値入力行の`?`ボタンで演算子、括弧、SCCWAV形式の簡易ヘルプを開けます。ヘルプは非モーダルで、Escまたは外側クリックで閉じられます。
