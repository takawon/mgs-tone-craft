# MGS Tone Craft

MGS Tone Craft（MGSTC）は、MGSDRV向けの複合音色エディタです。
PSG（YM2149）、SCC、OPLL（YM2413）の複数レイヤーを組み合わせ、
音色の編集、試聴、保存、MGSC 1.11でコンパイル可能なMML出力を行います。

現在は正式リリース前の開発段階です。

作業の引き継ぎ・やり残しは[HANDOFF.md](HANDOFF.md)を見てください。
仕様の正本は[SPECIFICATION.md](SPECIFICATION.md)、音源エンジン設計は[ENGINE_DESIGN.md](ENGINE_DESIGN.md)です。

## 対象音源

- PSG / SSG（YM2149）
- SCC
- OPLL（YM2413）

## ビルド

Windows、Visual Studio 2026、CMake 3.25以上を使用します。
詳しい手順は[BUILDING.md](BUILDING.md)を参照してください。

通常のBuildでは現行UIを正式な`mgstc.exe`として生成する。従来のWin32 GUI版は
ソースを含めて削除済みで、製品UIはJUCE版だけである。JUCE 8.0.15を使用し、JUCEおよびMGS Tone Craftは
AGPLv3の条件で配布する方針とする。

現行UIでは、総合・SCC・OPLL画面が1組のリアルタイム音源エンジンと
WASAPI出力、1台のMIDI入力サービスを共有します。画面切替では機器を
再初期化せず、フォーカス中の画面だけが演奏入力と波形表示を受け取ります。
総合画面の共通時間軸では、PSG・SCC・OPLL各レーンの音量、音程、音色番号を
最大65,535カウントまで横スクロールしてマウス描画できます。新規状態は空で、
`PSG追加`、`SCC追加`、`OPLL追加`から必要なチャンネルだけを追加します。
選択中のチャンネルは`選択ch削除`から確認後に削除でき、
空いたチャンネル番号は次回追加時に再利用されます。
各チャンネルは音量・音程・音色番号を重ねられる1本のソフトウェアエンベロープと、
共通のEND・ループ開始・終了を持ちます。チャンネル同士の時間軸は独立しています。
MMLトラック音量の`v`はソフトウェアエンベロープ外の独立した設定です。
選択中のチャンネルとEND、ループ開始・終了は時間軸上部の
インスペクターで確認・数値反映・ループ解除できます。
行数が増えた場合は縦スクロールします。自動1秒発音中は、
使用している音程を画面鍵盤でも点灯表示します。
SCC音色エディタでは32サンプルの波形直接編集、
プリセットと倍音・適用範囲、平均化・正規化・反転、位相と上下移動、
縦方向の波形拡縮、Undo／Redo、即時試聴を利用できます。ファイル読込・保存、
コピー、音声優先の貼り付け、WAV変換、Audacity選択範囲からの変換にも対応し、
単独機能はJUCE標準のベクター描画部品によるアイコンで表示します。
プリセット倍音は5位置の横バー、ON/OFF項目はスイッチで操作します。
選択中のプリセット波形はドロップダウンの
音色名の横へ表示し、開いた一覧の各項目にも波形プレビューを表示します。
Undo／Redoはファイル操作アイコンと同じ上段に配置します。
プリセット候補は現在波形と変更後波形を重ねて表示し、
置換または位相・極性・音量を調整したマージを確定前に1秒間試聴できます。
候補がある間は`取消`で破棄でき、`A/B`アイコンで確定波形と候補を交互に
手動試聴できます（即時発声OFFでも利用可能）。重ね表示は確定を緑実線、
候補を橙破線で示します。縦スケールバーはドラッグ中だけ候補を重ね、
離した時点で1回のUndo単位として適用します。
32サンプルは符号付き10進数と2桁16進数の両方から直接編集でき、確定波形の
MGSC `@s`定義を一時出力番号0～31とともに常時プレビューします。
波形グラフ背面へトレース用の背景画像を読み込め、位置・寸法・不透明度・
表示ON/OFFを調整できます（音色・MGSC・Undoへは影響しません）。
貼り付けはWAV音声、背景画像、MGSC `@s`の順で処理し、コピーは
UnicodeとANSI（CP932）の両形式を登録します。
SCC音色は右側の音色ライブラリへ名前・タグ・メモ・お気に入り付きで保存し、
後から読み戻せます。名前・タグ・メモの検索、編集取消、削除、外部`.mgstc`の
取り込みと選択音色の書き出しにも対応します。

OPLL音色エディタの移植も開始しています。現在はMOD／CARの
AM、PM、EG、KR、WS、MULT、KSL、TL、AR、DR、SL、RRとFeedbackを
意味パラメーターのまま編集でき、全値を共通レジスタ変換、1秒試聴および
MGSC `@v`プレビューへ同期します。スライダー操作のUndoはドラッグ終了で
1単位にまとめます。MOD／CARパネルには`emu2413`の
EG状態から生成した4秒間の実効エンベロープを共通振幅軸で常時表示し、
1秒地点のキーオフと、その後の減衰を比較できます。固定音色1～15は選択だけで試聴し、
「編集音色へ読込」で初めて編集値へコピーします。OPLL音色も右側の
音色ライブラリで検索、新規、読込、保存、別名保存、編集取消、削除、
外部`.mgstc`の取り込み・書き出しができます。SCC／OPLL画面は同じ
プロセス内の別ウィンドウとして開き、閉じた補助画面も再利用するため
再表示時にエディタを初期化し直しません。複数のアプリインスタンスが
起動された場合も、保存直前にライブラリの最新版を読み直してから更新します。
試聴中は`emu2413`が生成したOPLL単独PCMを
リアルタイム表示し、常に現在音程の2周期へ同期して見やすく揃えます。
OPLL画面上部からMGSC `@v`の
ファイル読込・保存、クリップボード貼り付け・コピー、Undo／Redo、
WAV／Audacityの近似変換を操作でき、最大6件の近似候補を前後に
切り替えて比較できます。音声付きクリップボードはテキストより先に
OPLL変換へ渡します。SCC／OPLL画面の
「開く」ボタンは、編集中の画面を残したままもう一方を別ウィンドウで起動します。
両エディタの変換アイコンは、固定条件で内部PCMを生成して既存の音声解析へ
渡す決定的な相互近似変換を行います。OPLLからSCCへ変換する場合は、
アタック、サステイン、自動または任意フレームから抽出位置を選択できます。
鍵盤はMGSC表記のC1～B8を全幅へ表示し、Ctrl押下中はPCキー演奏を停止します。
MIDI入力は右上のアプリ設定から選択・一覧更新し、接続状態を鍵盤上部で常時確認できます。
総合・SCC・OPLL画面の右上には、音源チップ側の音量値を変えずにWASAPIへ渡す
最終PCMを0～100%で調整する共通マスターボリュームつまみを置き、全画面と
再起動後の設定を同期します。SCC／OPLLの即時発音は、その左隣の
スピーカーアイコンで切り替えます。

## Audacityから変換を使うときの注意事項

OPLL／SCC単音色エディタの「Audacityから変換」は、Audacityで現在選択している音声範囲を一時WAVへ書き出して音色変換します。

使用前にAudacityの「編集」→「環境設定」→「モジュール」で`mod-script-pipe`を有効にし、Audacityを再起動してください。その後、音声トラック上で変換する時間範囲を選択してから「Audacityから変換」を押します。

`mod-script-pipe`を有効にすると、同じPC上で動作する他のプログラムからもAudacityを操作できる状態になります。信頼できないプログラムを実行する環境や複数ユーザーが同時利用する環境では有効にしないでください。連携を使用しない期間は、Audacityのモジュール設定で無効に戻すことを推奨します。
